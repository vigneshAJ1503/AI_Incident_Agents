# Query language: Grafana Loki (LogQL)
Every query starts with the stream selector `$index` (plus the service matcher shown above).
Fields listed as stream labels go inside `{...}`; every other field is a JSON key of the
line: extract it with `| json alias="field"` (Loki label names: letters, digits, `_`).
- `query_range` (log lines, `limit`, `direction`: `forward` = oldest first): sample lines of a
  pattern with a line filter, e.g.
  `{namespace="prod", app="payment-service"} |= "connection timeout" | json version="version", trace_id="trace_id"`
- `query` (instant metric query at `time`, counts over a `[range]`), e.g.:
  - `sum by (version, endpoint) (count_over_time({namespace="prod", app="payment-service", level="ERROR"} | json version="version", endpoint="endpoint" [15m]))`
  - `topk(10, sum by (msg) (count_over_time({namespace="prod", app="payment-service", level=~"ERROR|WARN"} | json msg="message" [15m])))`
- `query_range` with a metric query and `step` for a time series, e.g. errors per minute:
  `sum(count_over_time({namespace="prod", app="payment-service", level="ERROR"} [1m]))`
Label-filter regexes after `|` must match the WHOLE value: end a prefix with `.*`
(e.g. `| msg=~"Database connection timeout.*"`), or use a line filter `|= "..."`.
