# Tracker: Jira (JQL, mcp-atlassian tools)
- `jira_get_issue` with `include: "comments"`: a ticket's latest updates and workaround.
- `jira_search` with JQL that stays inside project `$project_key`. For example:
  - `project = $project_key AND labels = payment-service AND statusCategory != Done ORDER BY updated DESC`
  - `project = $project_key AND text ~ "connection pool" AND resolved >= "$lookback_start"`
